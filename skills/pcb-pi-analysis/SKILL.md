# PCB PI（Power Integrity）解析スキル

## 0. スキル概要

- **対象工程**: 基板開発の第5段階（検証）— 電源整合性（PI）解析。
- **適用タイミング**: アートワーク設計の電源・面構成・デカップリング配置完了後。修正ループ時は修正後の再解析。
- **実行モード**:
  - **オーケストレーション連携**: `pcb-orchestrator` からレイアウト情報とともに起動（通常）。
  - **単独実行**: ユーザーがレイアウト情報・電源レール一覧を提供して起動。
- **目的**: 電源ノイズ・電圧降下（IRドロップ）がICの動作保証範囲内に収まることを定量的に確認し、問題を具体化した修正指示を作成する。

## 1. エージェントの役割と責任範囲

- **役割**: 対象レールの選定、ターゲットインピーダンスの算定、PDN抽出と解析、IRドロップ解析、デカップリング評価、合否判定、PI解析報告書・修正指示書の作成。
- **責任範囲**:
  1. 電力予算の全レールを解析済みにする（網羅性）。
  2. デカップリング・配線・面構成の問題を、修正可能な形で具体化する。
  3. 判定に用いた基準・モデル・仮定を全て明記する。
- **責任範囲外**: レイアウト修正の実施（アートワーク工程）、SI解析・熱の詳細解析、電源ICの回路動作検証（回路工程の領域）。

## 2. 入力資料と前工程からの引き継ぎ情報

| 入力 | 形式 | 必須 | 出典 |
|------|------|------|------|
| レイアウト情報（面構成・デカップリング配置・配線幅・ビア・スタックアップ表） | Markdown（表）+ CADデータ | 必須 | `pcb-artwork-design` |
| 電源ドメイン一覧・電源ツリー・電力予算（電圧・電流・リップル許容） | Markdown（表） | 必須 | `pcb-system-design` |
| 電源IC・デカップリング部品の要素（ESR/ESL、容量値） | 表/PDF | 必須 | 回路BOM + 人が提供（C） |
| IC側の電流変化情報（τ遷移速度、瞬間電流） | テキスト/PDF | 条件付き（主要IC） | 人が提供 |
| グランドデザイン仕様書（消費電力・熱条件） | Markdown | 必須 | `pcb-grand-design` |

**受領確認手順**: ①全レールが電力予算に定義されていること ②デカップリングの容量・ESR/ESL・配置が分かること ③スタックアップ表（εr・厚さ・銅厚）が揃っていることを確認。

## 3. 詳細な作業手順

分類: [A=自動化 / B=エージェント実行＋人の承認 / C=人が実行]

1. **[A] 入力の受領確認と欠落チェック**。
2. **[A] 対象レールの選定**: 電流・瞬間変化・リップル感度から優先順位を付け（大電流・急変動・高感度順）、全レールを対象にする。
3. **[A] ターゲットインピーダンスの算定**: 各レールについて `Z_target = V_ripple_max / ΔI_transient` を計算する（第4節）。周波数帯域（デカップリングの自動化範囲）も定義する。
4. **[B] 解析プランの承認**: 対象レール・計算・解析方法・判定基準を提示し承認を得る。**必須承認ゲート①**。
5. **[A] PDN抽出**: レイアウトから電源経路（レール→面/配線→ビア→ICパッド）を抽出し、配線抵抗・インピーダンスを構成する。
6. **[A] IRドロップ解析**: 各レールのIC端で電圧降下を計算・解析し、動作範囲内かを確認する。放熱を含む温度影響は簡易評価する。
7. **[A] PDNインピーダンス解析**: 周波数領域で `Z(f)` を求め、`Z_target` と比較する（ツール使用時の抽出＋簡易計算の併用）。
8. **[A] デカップリング効果の評価**: 各容量の有効周波数（ESL由来）と配置効果を評価し、不足容量・配置不良を特定する。
9. **[A] 電源品質の確認**: レール間の干渉（共有経路・面分割）と、電源リファレンス電圧の変動を確認する。
10. **[A] 合否判定と重大度分類**: S/A/B/C を付与する（第4節基準）。
11. **[B] 報告書のレビュー**: 報告書と修正指示書の承認。**必須承認ゲート②**。
12. **[A] 処置**: S/A級は `pcb-artwork-design` へ修正指示書を送付（FR-1.7ループ）。この差戻しはA分類の実行であり、指摘・修正指示の承認は報告書受入（承認ゲート②）で済む。合格時は統括へ合格報告。
13. **[A] 自己検証**: 第8節のチェックリスト適用。

## 4. 設計判断基準と計算方法

### 4.1 判定基準（既定値・要求で上書き可）

| 解析項目 | 既定判定基準（例） |
|----------|--------------------|
| IRドロップ | レール電圧の3%以内（例: 1.0V → 30mV以内）、またはICの保証範囲内 |
| PDNインピーダンス | 全周波数帯域で Z_target 以下 |
| リップル | データシートの許容値以内（例: ±2〜5%） |
| レールの干渉 | 他レールへ の雑音振幅が消費側の許容値以内 |
| デカップリング有効性 | 3σ配置の最大距離に、必要容量が配置される（IC近傍の容量値合計 ≥ 計算必要値） |

### 4.2 主な計算方法

- **ターゲットインピーダンス**: `Z_target = V_ripple_max / ΔI_transient`（例: 1.2V、リップル2%（24mV）、ΔI=1A → 24mΩ）。
- **配線抵抗**: `R = ρ × ℓ / (w × t)`（銅: ρ = 1.72e-8 Ω·m、温度係数含む）。
- **IRドロップ**: `ΔV = Σ (I_要素 × R_経路)`。ビアは `R_via ≈ ρ × h / (π(r_out² − r_in²))`、または経験値を用いて推定。
- **デカップリング有効周波数**: `f_resonance = 1 / (2π√(L_total × C))`。ESL（配線・ビア込み）を含めて評価する。
- **配置分散の評価**: 面・パスの経路範囲を確認（目安: 高速電流はパス長1cmあたりのESL累積を評価）。

### 4.3 判断記録

対象レールの優先順位、判定基準の上書き、簡易モデル使用とその限界に判断記録を作成する。

## 5. 使用するEDA・解析ツール

| 用途 | ツール例 | 連携方式 | 自動化レベル |
|------|----------|----------|--------------|
| PI解析（Z・IR） | 市販PI解析ツール（PDN Z・IR解析。採用製品は制約記録で別途明記） | CLI実行 + 結果ファイル解析 | A（反復解析）/ B（判定） |
| 過渡解析（簡易） | ngspice（OSS、PDN等価回路） | コマンドライン実行 | A |
| 数値計算・可視化 | Python（numpy/matplotlib） | スクリプト | A |
| 部品要素の取得 | メーカー資料（ESR/ESL）（ユーザー提供） | ファイル交換 | C |

ツールが使用できない場合、等価回路（R+C+Lネットワーク）を構築して数値計算を行い、精度限界を報告書へ明記する（B承認）。

## 8. 検証方法と品質基準

### 8.1 チェックリスト

共通チェックリスト（`pcb-common` 第8.2節）に加えて:

- [ ] 電力予算の全レールが解析済み（または除外の場合判断記録あり）。
- [ ] 全レールで Z(f) ≤ Z_target が確認されている。
- [ ] 全レールの IC端 IRドロップが判定基準内である。
- [ ] デカップリングの必要容量・有効帯域・配置距離の根拠が記録されている。
- [ ] 全指摘に修正方法と再検証条件がある。
- [ ] 4大品質基準（完全性・整合性・追跡可能性・検証可能性）を満たす。

### 8.2 自動検証

- 対象レール表と解析実行ログの突合（実行漏れ検出）。
- 判定基準照合のスクリプト自動実行（数値照合）。
- IRドロップ計算の独立再計算（手計算 / スクリプト突合）。

## 9. エラー発生時の対応

共通手順（`pcb-common` 第9節）に従う。本工程固有の注意事項:

1. **電力予算の破綻検出**（レール電流が面・配線許容を超える）: S級として発行し、①面・配線幅の増加 ②ビア数増加 ③電源IC変更案 を併記して修正指示する。
2. **Z_target 不達**: 不足容量・ESL増大・配置遠距離の個別指摘で構成し、修正案（容量値・配置位置指定）を提示する。
3. **IRドロップ超過場合も即時S級**: 温度影響（＋20℃前提で再評価）を付記する。
4. **入力不備（部品要素データが欠落）**: 典型値で仮定して解析し、仮定値と限界を判断記録に明記する。S/A判定に関わる場合は取得依頼を発行する。

## 10. 次工程への引き渡し条件

### 10.1 アートワーク工程へ（修正指示時; FR-1.7ループ）

- [ ] 全S/A級指摘に「修正方法・部位・再検証条件」が定義されている。
- [ ] デカップリングの追加・変更・配置移動は、パッケージライブラリ名（任意値）を明示して指示されている。
- [ ] 共通引き渡しチェックリスト（`pcb-common` 第10節）が合格。
- [ ] 後続の再解析または報告に必要な代替入力（PI代替入力一式）が揃っていること: ①レール構成（電圧・リップル許容）②電流プロファイル（各レールのDC電流と過渡電流ΔI、または電流波形）③部品パラメータ（容量値・ESR/ESL実装込み、電源ICの出力インピーダンス/ドループ仕様）④PDN情報（面構成・ビア配置・デカップリングピン間距離）⑤IRドロップ評価の環境条件（周囲温度または想定最悪値）。いずれかの必須項目が入手できない場合、S/A級判定を前提とした推定は行わず、不足項目を列挙したデータ取得要求を出して停止する。

### 10.2 合格時（統括へ）

- [ ] 全レールで判定基準を満たす（または妥当化承認済み）。
- [ ] 報告書のレビュー（承認ゲート②）が承認済み。
- [ ] 残存リスク（温度条件、量産性、偏りが大きい部位等）を明記している。
