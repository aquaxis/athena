# PCBアートワーク設計スキル

## 0. スキル概要

- **対象工程**: 基板開発の第4段階（物理設計／アートワーク）。
- **適用タイミング**: 回路設計のリリースレビュー承認後。
- **実行モード**:
  - **オーケストレーション連携**: `pcb-orchestrator` から回路設計成果物とともに起動（通常）。SI/PI解析との差戻しループも統括下で実施する。
  - **単独実行**: ユーザーが回路図ソース・ネットリスト・BOM・制約一覧を提供して起動。
- **目的**: 電気的性能要求（SI/PI/EMC/熱）を満たす物理実装を確定し、製造可能で検証済みの設計データ一式を完成させる。

## 1. エージェントの役割と責任範囲

- **役割**: スタックアップ決定、設計ルール設定、部品配置、配線、電源面・リターンパス設計、熱・DFM配慮、DRC検証、製造データ生成。
- **責任範囲**:
  1. 回路設計のネットリストの全接続を物理層へ反映する。
  2. インピーダンス・トポロジー・長さ制約を配線で満たす。
  3. 電源インピーダンス（デカップリング近接・面構成）とリターンパスの連続性を担保する。
  4. DRC・DFM・熱の観点で検証し、S/A級問題を解消してから後工程へ提出する。
- **責任範囲外**: SI/PIの詳細解析・合否判定（解析工程）、製造可否の最終判断（製造元）。

## 3. 詳細な作業手順

分類: [A=自動化 / B=エージェント実行＋人の承認 / C=人が実行]

1. **[A] 入力の受領確認と欠落チェック**。
2. **[B] スタックアップ（層構成）の決定**: 制約（インピーダンス、電源・GND面数、配線密度、コスト）から層数・材料・厚さ・層順の案を生成し、計算（第4節）を添えて承認する。**必須承認ゲート①（スタックアップ）**。
3. **[A] 設計ルール設定**: トレース幅・クリアランス・ビア径／アニュラ、ビア間隔、パッド接続（サーマルリリーフ）などルールをCADへ設定する。
4. **[A] 部品配置**: ①主要IC・コネクタを配置構想に従い配置 ②機能ブロックごとに配置 ③デカップリングを各電源ピン近傍へ ④アナログ/デジタル/RFスペース分離 ⑤熱源の配置と放熱パス確保 ⑥テストポイント・加工座標の確定。
5. **[B] 配置の承認**: 配置図（主要IC・コネクタ位置）を提示し承認を得る。**必須承認ゲート②（配置）**。
6. **[A] 配線**: ①制約ネットから優先配線（DDR・高速 シリアル・クロック） ②差動ペア・トレース幅・長さ マッチ ③バスと一般配線 ④パワーの配線（層／幅） ⑤リターンパス連続性の確認（切れ目の許容箇所を限定）。
7. **[A] 電源・リターン設計**: 面の構成、デカップリング配置の最終化、パラレル接続の電流負荷の均衡を確認する。
8. **[A] 熱・EMC配慮の確認**: 放熱ビア・シールド効果、EMI源と受感部の距離評価を記録する。
9. **[A] DFM実施**: 製造能力確認（最小線幅・最小ビア径・面数層数の余裕）と、必要なら修正。
10. **[A] DRC・リターンパス検証**: CADのDRC・リターンパス検査スクリプトを実行し、全警告解消または妥当化（判断記録）。
11. **[A] SI/PI解析への引き渡し（解析前の暫定引き渡し・リリースではない）**: 第10.1節の条件（機械検証）で解析工程へ送る。この引き渡しに追加の人的承認は不要（スタックアップ①・配置②の承認が内容を担保）。解析は暫定配置・暫定配線に対する反復検査である。差戻し時（修正指示）は第12項に従い処理する。
12. **[A] SI/PI修正ループの受入と再検証（差戻しループ）**: SI/PI解析の修正指示書を受領したら第9節の手順で修正し、DRC・配線整合・関連検証を再実行し、同一条件で再引き渡す。全S/A級指摘が解消されるまでループを反復する（同一指摘が初回を含めて3回目に達したらエスカレーション）。**リリースはこのループが完了するまで開始しない**。
13. **[A] 製造データ生成**: ループ完了後の**最終データ**から Gerber（RS-274X）、ドリル（Excellon）、組立図、ピック&プレース、3Dデータ（STEP）を生成し、整合検証（層名・径・単位の突合）を行う。
14. **[B] リリースレビュー**: 最終データ（製造データ一式を含む）・全検証結果・SI/PI解析合格報告を提示し承認を得る。**必須承認ゲート③（リリース）** — 承認対象は修正ループ完了後の最終データであり、解析前の暫定データではない。承認後に統括の完了系へ引き渡す。

## 4. 設計判断基準と計算方法

### 4.1 スタックアップの判断基準・計算

- **層数概算**: 高密度IC（BGA）の breakout必要数・信号数とルーティング密度から目安を算出。電源層／GND層は電源ドメイン数とインピーダンス要求から決定。
- **特性インピーダンス（近似式）**:
  - マイクロストリップ: `Z0 ≈ (87 / √(εr + 1.41)) × ln(5.98h / (0.8w + t))`
  - ストリップライン: `Z0 ≈ (60 / √εr) × ln(4h / (0.67π(0.8w + t)))`
  - 差動: `Zdiff ≈ 2 × Z0 × (1 − 0.48e^(−0.96s/h))`
  - （h: 誘電体厚さ、w: 線幅、t: 銅箔厚さ、s: 線間隔。許容差は製造元の工程能力に基づく±10%以内を目標）
  - 目標値に合うように、製造元の材料パラメータ（εr、tanδ）と実際の厚さを使用してCAD側計算と突合する。
- **電流容量**: IPC-2221を基準に、温度上昇要求を満たす線幅・銅厚を算出（内層は＋30%余裕）。大電流パスはビア数を `N = I / I_ビア許容` で算出。
- **リターンパス**: 信号層の直下に連続参照面を配置（層順選択）。分割・切れ目があるネットは明記し、ループ面積を最小化。

### 4.2 配置・配線の判断基準

| 判断事項 | 判断基準（例） |
|----------|----------------|
| 主要IC位置 | コネクタ・I/O構造、信号距離・負荷数、熱の位置 |
| デカップリング配置 | 対応電源ピンと最短距離、複数容量なら重要度順。面（グランド面）接続 |
| 配線順序 | 制約強いネット（制約表の優先度S/A）から配線する |
| アナログ・デジタル分離 | 高SNR部はフロア分離し、共通GND面を1点接続または全面を共有（構成判断記録必須） |
| クリアランス | 高電圧は耐圧・表面距離規格（IPC-2221ガイド）に従う |

### 4.3 判断記録

スタックアップ・配置・トポロジー・層の割り当て・面切れ目の処理等に判断記録を作成する。

## 8. 検証方法と品質基準

### 8.1 チェックリスト

共通チェックリスト（`pcb-common` 第8.2節）に加えて:

- [ ] ネットリストの全接続がレイアウトで接続許可済み（Ratsnest（未接続リスト）＝0）。
- [ ] 全制約ネットが、制約一覧に定めた設計条件（線幅・差動ペア・トポロジー・長さ）どおり配線されている。
- [ ] インピーダンス設計値が、目標インピーダンスに対して±10%以内（4.1節の許容差基準）に収まっている。
- [ ] 全電源レールにデカップリングが配置され、大電流パスの銅箔幅・ビア数が電流容量計算値を上回る。
- [ ] GND参照面の切れ目を跨ぐ 重要信号が無い（跨ぐ場合は判断記録あり）。
- [ ] DRC・DFMの全警告が解消または判断記録で妥当化。
- [ ] 製造データ（Gerber・DRC・ドリル・組立図・P&P）が整合検証済み（層名・径・単位の突合）。
- [ ] 4大品質基準（完全性・整合性・追跡可能性・検証可能性）を満たす。

### 8.2 自動検証

- DRC・リターンパス・クリアランス・Ratsnest・ネットリスト突合をスクリプトで実行する。
- Gerber／ドリルのヘッダ情報（単位・径・フォーマット・層名）の自動突合を行う。
- 熱簡易計算の再現（入力値・式・結果）を記録し、レビューで可視化する。

## 9. エラー発生時の対応

共通手順（`pcb-common` 第9節）に従う。本工程固有の注意事項:

1. **Ratsnest残留（未接続残り）**: ネットリスト漏れか実配線漏れかを突合で判別し、実配線漏れは即時修正（A）、リスト不一致は回路工程への差戻し判断を記録する。
2. **DRC違反**: 重なり・クリアランス違反は即時修正（S/A）。許容が必要な場合は判断記録で妥当性を明示し、下流（SI/PI・DFM）に影響を開示する。
3. **制約未達（インピーダンス・長さ）**: 優先度S/A制約の未達は修正ループ（配線・スタックアップ調整）。B級は判断記録で妥当化し、SI解析へ検証依頼を追加する。
4. **SI/PI解析からの差戻し**: 修正指示書の各項目を実施し、修正後に本工程のDRC・配線整合・製造データ再生成を行い、再引き渡す。修正内容と結果は判断記録に記録する。
5. **DFM限界超過**（最小線幅等を製造能力が超える）: スタックアップまたはルールを再検討し、製造可能な条件に調整（B 承認）。

## 10. 次工程への引き渡し条件

### 10.1 SI/PI解析工程へ（`pcb-si-analysis` / `pcb-pi-analysis`）

- [ ] レイアウトデータ（位置・層・ 配線幅・スタックアップ情報）が利用可能な形で書き出されている。
- [ ] 重要ネット一覧（速度・トポロジー優先度順）を明示している。
- [ ] 電源ドメイン一覧・電力予算・スタックアップ表を送付している。
- [ ] 解析に必要な材料定数（εr、tanδ、銅箔厚さ等）の未確定値はユーザーから確認済み。
- [ ] **SI用必須入力**: 幾何計量表に加え、①ドライバ特性（IBIS/SPICEモデル、またはエッジレート＋出力インピーダンス＋振幅レベル）②動作条件（電源電圧・信号振幅・クロック速度/タイミング仕様）③判定基準（オーバーシュート・クロストーク・タイミングマージン・アイ/BER目標）が、解析側が参照可能な形（同梱または出典パスの明示）で揃っている。出典はシステム設計の動作条件・回路成果物・ユーザー提供データ。
- [ ] **PI用必須入力**: 幾何計量表に加え、①レール構成（電圧・リップル許容）②電流プロファイル（DC電流＋過渡電流ΔIまたは波形）③部品パラメータ（容量値・ESR/ESL実装込み、電源ICの出力インピーダンス/ドループ仕様）④PDN情報（面・ビア・デカップリングピン間距離）⑤IRドロップ評価用の環境条件（周囲温度または想定最悪値）が同様に揃っている。
- [ ] **不足時の停止条件**: 上記の非幾何入力（ドライバ特性・電流プロファイル・ESR/ESL等）が欠落し、アートワーク側と参照可能な成果物からも入手できない場合、この引き渡しは進行せず、欠落項目を列挙したデータ取得要求を統括経由で上位（システム設計/回路設計/ユーザー）へ発行する。幾何情報だけでは SI/PI の定量判定は成立しないため、幾何情報単体での引き渡しは不十分とする。

### 10.2 リリース（オーケストレーション完了・製造準備）へ

- [ ] 全DRC・Ratsnest・突合検証がクリア。
- [ ] SI/PI解析報告書のS/A級指摘が全て修正・再検証済みである。
- [ ] 製造データ一式（Gerber・drill・組立図・P&P・3D）が生成・整合検証済み。
- [ ] リリースレビュー（承認ゲート③）の承認が記録されている。**ゲート③は SI/PI差戻しループ完了後の最終データを対象とする**（解析前の暫定データへの承認は無効; 解析前の担保はゲート①スタックアップ・②配置が行う）。
- [ ] 共通引き渡しチェックリスト（`pcb-common` 第10節）全項目合格。
- [ ] リリースの製造データ（Gerber/drill/組立図等）に代替形式は認められない。製造に必要なデータを作成できない場合、リリースを停止し、欠落した能力を明示してエスカレーションする。
